# CraveHouse: Food Delivery Website

A responsive single-page food delivery website. Visitors can browse the menu, filter by category, build a cart and place a simulated order. Built with plain HTML, CSS and JavaScript, with no frameworks or build step.

**Live demo:** https://cravehouse-food-delivery.netlify.app

## Features

- Menu of 15 items across five categories: Deals, Starters, Mains, Drinks and Desserts
- Category filters
- Cart with a live item counter, quantity controls, item removal and a running total
- Checkout form with delivery details and a choice of Cash on Delivery or card (demo)
- Simulated order placement that returns a mock order ID
- Hero section with background video
- Responsive layout for phone, tablet and desktop

This is a front-end demo: there is no backend and no real payment processing.

## Tech Stack

- HTML5, CSS and vanilla JavaScript
- Hosting: Netlify

## Run Locally

No installation needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/galaxyshine701/cravehouse-food-delivery.git
   ```
2. Open `index.html` in your browser.

## Project Structure

```
index.html
assets/
  css/styles.css     all styles
  js/data.js         menu items and categories
  js/main.js         filters, cart and checkout logic
  media/             food photos and hero video
```
